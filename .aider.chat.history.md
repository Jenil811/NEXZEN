#### Build a complete, production-ready 3D marketing agency website for NexZen Marketing Agency. This is not a portfolio toy — it must work as a real client-converting agency website inspired by Ogilvy, Instrument, Code and Theory, and Monks.  
####   
#### === CORE PHILOSOPHY ===  
#### The website follows one visual idea: "FROM ATTENTION TO GROWTH."  
#### The 3D environment evolves as the visitor scrolls — chaotic particles organize into systems, shapes become visual identities, systems connect into performance, data flows into growth, everything converges into NEXZEN.  
#### Result must feel: 70% strategic agency website + 20% immersive 3D + 10% experimental technology.  
#### NOT a "website with some 3D effects." An interactive digital experience that PROVES NexZen can build attention, brands and growth.

#### React + Vite + TypeScript  
#### Tailwind CSS

#### Lenis (smooth scroll)  
#### React Router DOM (for /work/[slug] pages)  
#### Lucide React (icons)
